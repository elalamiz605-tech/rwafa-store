# RWAFA

Boutique de streetwear inspirée de la culture amazighe du Rif : hoodies, t-shirts et chaussettes.
Site statique (HTML, CSS, JavaScript), hébergé sur GitHub Pages.

- Designs originaux : le ⵣ, les motifs de tapis du Rif, Nador, Al Hoceima. Aucun drapeau politique.
- Les photos produits sont des visuels générés par IA, à remplacer par des photos d'échantillons réels.
- Le paiement est une démo : aucun paiement n'est encaissé tant qu'un prestataire (Shopify, Stripe) n'est pas branché.
